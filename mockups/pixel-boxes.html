Pixel scribe boxes, in Old Fax

Colour band and lotus frieze, refined. The text is still Old Fax at 2×, but the borders, tabs, stamps and icons now sit on a grid twice as coarse: one border pixel is 4 screen pixels. The motifs are simplified to match, so the box reads at the same scale as the rest of the game. The icons are stand-ins for your hieroglyphs.

Part 2 · Feedback types

Pick a border for all five types. The rules come from your table. The tab colour, icon and stamp mark each type: "+ Journal" and "+ Rites" for things that get recorded, and "while hauling" for an instruction that stays pinned.

Object description

Replaced when another object is clicked. The first look records the figure in the journal.

NPC request

Stays until your next interaction, and the request is added to the Rites page.

Environmental hint

Replaced as usual. An important one can be noted in the journal.

Task completion

Lit up for a moment (the gold rule and green tab), then it settles into an ordinary box. The text stays.

Minigame instructions

Pinned for as long as the minigame runs. The driver's calls show elsewhere, so they don't overwrite it.
